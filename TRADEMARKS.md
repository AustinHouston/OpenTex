# The OpenTex name and icon

OpenTex's code is free software under the [GNU Affero General Public License v3](LICENSE). You may
copy it, change it and share your changed version under that license.

The license covers the code. It does not give permission to use the **OpenTex name** or the
**OpenTex icon** for something else. This keeps it clear to people which app is the original and
where to get it.

**Please do:**

- Say that your project is *based on OpenTex* or *a fork of OpenTex*, with a link to
  https://github.com/AustinHouston/OpenTex.
- Use the name to refer to OpenTex itself (in articles, tutorials, reviews and comparisons).
- Package an unchanged copy of an official release for a software catalog or a Linux
  distribution, as long as it is clearly the official OpenTex.

**Please don't, without asking first:**

- Release a changed version under the name OpenTex, or a name that could be mistaken for it.
- Use the OpenTex icon (or something close to it) for a changed version or another product.
- Suggest that your version is official, or endorsed by the OpenTex project.

If you ship a changed version, give it its own name and icon, and keep the copyright notices and
license as the AGPL requires.

Questions, or want to ask permission? [Open an issue](https://github.com/AustinHouston/OpenTex/issues).
