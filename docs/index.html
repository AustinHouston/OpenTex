Collaborate

Comments that work just like Word

Select text in the editor or in the PDF, click + Comment, reply, resolve.

Your .tex stays clean: comments are kept in a small file in the project folder, so they travel with it over email, Dropbox or git, and never appear in the PDF. If a collaborator edits the text in another editor, OpenTex finds each comment’s place again, and anything it can’t place gets a one-click Re-link.

Navigate

SyncTeX: source and PDF, linked

Double-click anywhere in the PDF to jump to that line of source.

Press Ctrl/⌘ + J to jump from the source to the matching spot in the PDF.

Install

Up and running in a minute

The first launch shows a one-time security prompt. Here is how to get past it.

Mac Download .dmg

  1. Open OpenTex-mac.dmg and drag OpenTex into Applications. Not allowed to? Drag it to your Desktop or Documents instead. It runs from anywhere.
  2. Open OpenTex. The first time, macOS says it can't verify the developer. Click Done.
  3. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to OpenTex. You only do this once.

On macOS 14 or earlier you can instead right-click the app, choose Open, then Open again.

Windows Download .exe

  1. Double-click OpenTex-windows-setup.exe. It installs just for you, with no admin prompt.
  2. If Windows says "Windows protected your PC", click More info → Run anyway.

Installer blocked? Use the portable version: right-click the zip → Properties → tick Unblock → OK, then Extract All and double-click OpenTex.exe.

On a work or government computer?

Some managed computers hide the Open Anyway / Run anyway buttons because policy only allows signed apps. If you don't see them, ask your IT help desk to approve OpenTex. It's open source, so they can review the code on GitHub.
